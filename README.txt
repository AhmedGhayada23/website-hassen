HASEEN | الحصين — الموقع المحلي

طريقة التشغيل (الأسهل):
  افتح الملف HASEEN-offline-single-file.html مباشرة بالنقر المزدوج — يعمل بدون أي إعداد.

طريقة التشغيل (الملفات المنفصلة):
  المتصفحات تمنع تحميل ملفات JS عند فتح index.html مباشرة من القرص، لذلك شغّل خادماً محلياً داخل هذا المجلد:
    python -m http.server 8000
  أو:
    npx serve .
  ثم افتح: http://localhost:8000

هيكل الملفات:
  index.html              الصفحة الرئيسية وكل الصفحات (التصميم والمنطق)
  css/styles.css          الأنماط العامة والحركات
  js/haseen-content.js    كل النصوص العربية والإنجليزية (عدّل المحتوى من هنا)
  js/support.js           محرك تشغيل الواجهة
  assets/haseen-mark.png  شعار الحصين

ملاحظة: النماذج تجريبية وتحتاج ربطاً بخدمة إرسال قبل الإطلاق.
